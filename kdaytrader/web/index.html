한국주식 실시간 데이트레이딩 엔진

기술적 분석 앙상블 + 퀀트 알파 + 거시·섹터·뉴스 컨텍스트로 매수·매도 시그널을 만들고, 리스크 규칙에 따라 자동(또는 알림만) 매매합니다.
아래에서 실행 방식을 고르면 바로 시작됩니다. 처음이라면 체험하기를 눌러 보세요.

🎮

체험하기

시뮬레이션 시세로 프로그램 전체를 빠르게 재생합니다. 인터넷·계좌 불필요.

🔔

실시간 시그널만

네이버 시세로 실시간 매수·매도 신호와 뉴스·거시 컨텍스트를 봅니다. 주문은 하지 않습니다.

🧾

페이퍼 트레이딩

네이버 실시간 시세로 가상 계좌에서 자동매매를 검증합니다. 실제 돈은 쓰지 않습니다.

🏦

한국투자증권 연동

KIS Open API 실시간 체결·호가로 모의투자/실전 자동매매. 설정에서 앱키·계좌를 먼저 입력하세요.

미설정

시작 가이드

  1. 체험하기로 대시보드·차트·시그널 흐름을 익힙니다.
  2. 설정에서 관심종목, 리스크(1회 손실 %, 손절 배수), 진입 시간대를 조정합니다.
  3. 백테스트로 최근 분봉에서 전략 성과(승률·손익비·낙폭)를 확인합니다.
  4. 장중에 실시간 시그널만 → 페이퍼 트레이딩으로 검증합니다.
  5. 충분히 검증한 뒤 한국투자증권 모의투자(kis.paper: true)로 넘어갑니다.

주의

  • 어떤 전략도 수익을 보장하지 않습니다. 모든 손실은 사용자 책임입니다.
  • 정규장은 평일 09:00~15:30. 장 마감 후에는 시세가 멈춰 있어 시그널이 나오지 않습니다.
  • 네이버 시세는 비공식 API 로 예고 없이 바뀔 수 있습니다.
  • 실계좌 주문(kis.paper: false)은 반드시 모의투자로 충분히 검증 후 사용하세요.

인터넷 데이터 연결 진단

네이버 시세·차트·지수, 뉴스 RSS, 한국투자증권 API, 텔레그램 연결을 각각 확인합니다. 실시간 모드를 쓰기 전에 한 번 눌러 보세요.
